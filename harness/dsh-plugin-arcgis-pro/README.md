# ArcGIS Pro natural-language mapping / 自然语言制图

This directory is a Harness configuration bundle, version 0.4.2. Before installing it, run `scripts/prepare-harness-plugin.py` from the repository root. The script generates the required local `cordis.patch.yml`. Install this directory through Harness → Plugins → Add plugin, keep it in place, open Pro with the bridge installed and test in a new chat.

这是 0.4.2 版 Harness 插件。安装前在仓库根目录运行准备脚本，生成必要的本机 `cordis.patch.yml`，再通过 Harness 插件页面添加该目录。保留目录，打开已安装连接桥的 Pro，在新聊天验证。

See the repository's bilingual guides. Accounts are managed by Harness; this bundle contains no model credentials.

详见仓库中英文教程。账户由 Harness 管理，本插件不包含模型凭据。

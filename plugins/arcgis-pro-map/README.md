# ArcGIS Pro Codex plugin

From the repository root run `scripts/install-codex-plugin.ps1`. Open a new Codex chat and select **ArcGIS Pro 自然语言制图**. Install and load the Pro bridge first. Verify an actual `list_sessions` / `get_active_map` response before analysis.

在仓库根目录运行安装脚本；先安装 Pro 连接桥并重启 Pro，在新 Codex 聊天选用插件，读取实际地图回执再开始分析。
